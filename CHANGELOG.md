# История изменений

## 0.6.10 — 2026-07-26

- светофор сохраняет увеличенный размер и нижний отступ после изменения размера и повторной активации окна;
- нижние панели снова используют мягкие акцентные кнопки TouchPilot вместо системного стиля текущей macOS.
- GitHub Release теперь собирается на macOS 26 ARM64 с Xcode 26.6 — в том же окружении, что и локальная `.app`.

## 0.6.9 — 2026-07-26

- направления слайдов вдоль левого и правого края распознаются по полному движению, а предпросмотр больше не разворачивает анимацию в обратную сторону;
- зоны клика сделаны шире и остаются разделёнными;
- распознавание круга требует почти замкнутого полного контура и больше не принимает полукруг за круг;
- кнопки управления окном немного увеличены и опущены ниже.

## 0.6.8 — 2026-07-25

- восстановлено стандартное положение и размер кнопок управления окном;
- меню добавления действия снова отображается компактной кнопкой «+»;
- ползунки чувствительности снова используют выбранный акцентный цвет;
- образ DMG получил иконку TouchPilot.

## 0.6.7 — 2026-07-25

- добавлена автоматическая ежедневная проверка обновлений через GitHub Releases;
- добавлена ручная команда «Проверить обновления…» в меню;
- добавлено скачивание DMG в папку «Загрузки» с последующим открытием;
- повреждённый файл пресета больше не перезаписывается автоматически;
- восстановлено безопасное адаптивное определение формата raw-touch;
- добавлена сборка DMG и автоматическая публикация релизов через GitHub Actions;
- расширена документация и добавлены скриншоты интерфейса.

## 0.6.6

- профили приложений и последовательные действия;
- расширенный набор жестов и системных команд;
- светлая и тёмная темы;
- импорт и экспорт настроек.
